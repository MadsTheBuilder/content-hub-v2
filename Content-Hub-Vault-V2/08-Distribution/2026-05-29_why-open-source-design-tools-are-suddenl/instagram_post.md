# Instagram Carousel

**Slide 1:**
Your coding agent already knows how to design.
Open Design just figured out how to prove it.

---

**Slide 2:**
It doesn't bundle its own AI.
It hands the entire design loop to whatever CLI you already have — Claude Code, Cursor, Codex, Devin, Copilot, 11 others.

---

**Slide 3:**
On startup, it scans your PATH and checks config dirs like `~/.claude/` to detect installed agents.
Then it negotiates capabilities: surgical edits, streaming format, skill loading. No config file needed.

---

**Slide 4:**
71 brand-grade design systems. 19 skills.
Outputs: web prototypes, mobile screens, slides, videos, HTML/PDF/PPTX/MP4 — all from a prompt.

---

**Slide 5:**
For Claude Code, it symlinks the skill directly into `~/.claude/skills/`.
For Cursor, it writes `.cursorrules`. Each agent gets instructions in the format it actually understands.

---

**Slide 6:**
The daemon normalizes 5 different streaming formats in real time — claude-stream-json, acp-json-rpc, pi-rpc, plain text — so you see live tool calls in the UI regardless of which agent is running.
