# LinkedIn Post

Your coding agent already knows how to design.

Most developers don't realize it yet — but Open Design just made that capability visible.

Here's what it actually does:

• **Uses your existing CLIs, not its own** — Claude Code, Codex, Cursor, Copilot. It scans your PATH on startup, detects what's installed, and delegates the full design loop to the agent you already trust.

• **Injects design skills, not new models** — For Claude Code, it symlinks a `SKILL.md` into `~/.claude/skills/`. For Cursor, it writes `.cursorrules`. No new AI subscription. Just structured context your agent already knows how to consume.

• **71 brand-grade design systems included** — Pick one, and it becomes the token layer your agent codes against. Consistent output without a designer in the loop.

• **Generates real artifacts** — Web, desktop, and mobile prototypes. Slides. HTML/PDF/PPTX/MP4 export. Sandboxed preview built in.

• **16 supported agent CLIs** — Each gets its own adapter handling CLI args, streaming format, and output normalization. The UI shows live progress regardless of which agent is running underneath.

The architecture is genuinely clever: it's not replacing your agent, it's teaching it a new skill domain.
