# Instagram Carousel

**Slide 1:**
Your coding agent — Claude Code, Cursor, Codex — can already design. Open Design just hands it the keys.

---

**Slide 2:**
Most design tools bundle their own AI. Open Design flips that.

It scans for whatever CLI you have installed and hands the *entire* design loop to it. No proprietary agent. No lock-in.

---

**Slide 3:**
On startup, it checks your PATH and probes config dirs like `~/.claude/` to find what's there.

Then it figures out what your agent can do — surgical edits, streaming format, skill loading. Same agent. Now design-aware.

---

**Slide 4:**
16 coding-agent CLIs supported. Claude Code is the reference implementation. Devin uses ACP protocol. Cursor gets a `.cursorrules` file dropped into the project.

Each adapter handles its own quirks. You get a live progress card in the UI while it runs.

---

**Slide 5:**
71 brand-grade design systems. 19 built-in skills.

Web prototypes, mobile screens, slides, images, video — exported to HTML, PDF, PPTX, or MP4. All local. All running through the agent you already have.

---

**Slide 6:**
The design system lives in `DESIGN.md`. The skill lives in `SKILL.md`.

Your agent reads both and builds. It's the same skill-injection pattern Claude Code users already know — just pointed at pixels instead of code.
