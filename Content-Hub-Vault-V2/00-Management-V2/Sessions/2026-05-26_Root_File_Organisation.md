### Path-constant fixes (in moved files)

All `Path(__file__).parent` references to project root were broken by the move and have been updated to `Path(__file__).parent.parent`:

- `app/control_room.py:20` — `VAULT` path
- `app/control_room.py:302` — `repo` for subprocess cwd
- `app/runner.py:8` — `REPO` for subprocess cwd
- `app/vault_index.py:6` — `VAULT` path
- `scripts/github_trending.py:20` — `ROOT` (also feeds `OUTPUT` and `LOG_DIR`)

Two subprocess calls in `app/control_room.py` that spawn `github_trending.py` by relative path were updated:

- Line 97: `["python", "github_trending.py"]` → `["python", "scripts/github_trending.py"]`
- Line 315: same change in the full-pipeline runner

The `.bat` files were also updated to point at the new script paths. The `cd /d` to project root was already in both, so cwd is unchanged — only the script argument needed updating.

Inside `bin/run_github_trending.bat` the Task Scheduler instruction comment was updated to reflect the new `bin\` path. User confirmed no live Task Scheduler entry exists right now, so no scheduled job was broken.
