No LLMs Involved

Deterministic Systems

Pure logic — same input always produces the same output

GitHub Scraper
GitHub Trending
scripts/github_trending.py
Queries GitHub Search API across 3 AI topics (llm, ai, machine-learning). Merges results, deduplicates by repo ID, sorts by star count. Writes daily pulse to 04-Trends/ with velocity scores.
Source Filter
Primary Source Filter
skills/research_sources.py
Regex allowlist/blocklist on every URL entering the pipeline. Scrapes YouTube video descriptions via yt-dlp. Fires a Claude/NIM backstop if fewer than 5 credible sources are found.
Vault Index
Vault Index
app/vault_index.py
Sorted file listings for Control Room dropdowns. Reads research briefs, ideas, hooks, and outlines from vault folders. Returns newest-first lists via mtime sorting — no LLM at all.
Doc Crawler
Researcher Crawler
skills/researcher_crawler.py
GitHub API crawler that discovers primary documentation for a repo. Traverses the file tree, scores candidates by relevance heuristics, returns a ranked DocCandidate list for research input.

06
Quality Gates

Research Guardrails

Three runtime controls baked into the research pipeline

01
Source Filter
skills/research_sources.py
  • Scrapes YT video descriptions with yt-dlp
  • Allowlist: arxiv, GitHub, official docs, PDFs
  • Blocklist: Reddit, Twitter, Medium, Substack
  • If <5 sources → Claude/NIM backstop fires
arxiv github docs reddit medium
02
Question Budget
skills/research_plan.py
  • Default cap: 12 questions per research run
  • Dedup: >60% word overlap = question skipped
  • Adaptive follow-ups: 0–2 generated per answer
  • Stats emitted: asked / deduped / followups / remaining
budget = 12 overlap > 60% → skip
03
NIM Judge
skills/helpers/nim_picker.py
  • LLM-as-judge step before research begins
  • Asks NIM: which report structure matches goal?
  • Goal: "explainer" or "technical"
  • Returns None → halts code path if no match
explainer technical NONE → halt
07
Human in the Loop

BLOCKING Gates

Three hard stops — pipeline cannot advance without a human decision

/researcher
blocking
"Which repos do you want to research?"
Lists repos from GitHub Trending. "Never auto-select repos without the user's explicit choice." Pipeline does not run until repos are confirmed.
/ideation
blocking
"Which idea do you want to pursue? Reply with a number (1–9)."
Surfaces 9 generated video angles. Will not suggest /hook or advance in any direction until a number is explicitly provided.
/hook
blocking
"Which hook do you want to run with?"
Shows 5 hooks as numbered Spoken Lines (Kallaway patterns). "Do not suggest /outline until you have the answer." Enforced by SKILL.md instruction.

Quality Assurance

The Eval System

Behavioral test suites — one per skill, scored in-browser

evals/evals.json
Array of test cases. Each has a prompt, expected output description, and a list of assertions to score.
iteration-N/eval-*/eval_metadata.json
Individual test input + assertions. Claude runs the skill; a human scores each assertion pass/fail.
iteration-N/eval_review.html
Browser-based scoring dashboard. Export to XLSX. Shows pass rate across all assertions and runs.
Assertions check:
→ Did it find the right files by name?
→ Single confirmation only — not multiple?
→ Filenames shown in the confirmation?
→ Correct CLI flags used?
→ Next pipeline step suggested?
