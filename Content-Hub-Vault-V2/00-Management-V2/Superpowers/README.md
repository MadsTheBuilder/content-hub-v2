# V2 Superpowers

Mirrors `00-Management/Superpowers/` — workflow skill files (orchestrated-execution, dispatching-parallel-agents, TDD, etc.).

**Default behavior:** V2 reuses the existing V1 Superpowers at `00-Management/Superpowers/`. They're project-agnostic workflow primitives.

This folder is only populated when V2 needs a divergent version of a skill — e.g., a V2-specific orchestration pattern that doesn't fit V1's SaaS-stack model.
