# Session: T3.2 — General Trending Scrape Implementation

## What Was Done

Implemented platform-wide trending content discovery outside the keyword universe. Users can now discover emerging topics not filtered by their workflow's topic pillars.

## Files Changed

### 1. `backend/research/apify_client.py`
- **Added `scrape_general_trending(platform: str)`** — Fetches platform-wide trending content without keyword filtering
  - TikTok: uses broad hashtags (trending, viral, fyp, foryou)
  - Instagram: uses broad hashtags (trending, viral, explore, reels)
  - YouTube: uses /feed/trending page
  - LinkedIn: returns empty list (no good public trending actor)
  - Results tagged with `workflow_id='__general__'` for differentiation
  - Returns top 30 results sorted by organic_score
  
- **Added `_build_general_trending_input(platform: str)`** — Helper to construct Apify actor inputs without keyword filters
  
- **Added `_mock_general_results(platform: str)`** — Mock data (8 items) returned when Apify key is absent
  - Preserves mock mode fallback behavior

### 2. `backend/scheduler/jobs.py`
- **Added `job_general_trending()`** — Weekly scheduled job
  - Imports `scrape_general_trending` from apify_client
  - Runs for each platform: TikTok, Instagram, YouTube
  - Deduplicates against existing general trending posts
  - Logs items stored per platform
  
- **Updated `start_scheduler()`** — Now schedules 6 jobs (was 5)
  - New job: `CronTrigger(day_of_week="tue", hour=5, minute=0)` — Tuesday 5:00 AM UTC
  - Cron expression: `0 5 ? * TUE` (APScheduler format)

### 3. `backend/intelligence/suggestions.py`
- **Blending logic added** — General trending items mixed into suggestions with reduced weight
  - Fetches both keyword-based trending and general platform trending (limit 10)
  - Applied 0.6x weight multiplier to general trending posts via `_blended_score()` function
  - Workflow-specific trending takes priority (1.0x weight)
  - General trending acts as fallback when keyword signals are weak
  
- **User awareness flag** — Items from general trending marked with `discovery_type='general_platform_trend'`
  
- **Ranking unified** — Both trending sources ranked together by memory match score + organic score tiebreaker

## Key Decisions

- **`__general__` workflow_id**: All general trending items tagged with this sentinel value to distinguish from workflow-specific content
- **0.6x weight multiplier**: General trending scores lowered by 40% vs keyword-based to maintain user focus on their defined topics
- **Weekly Tuesday 5:00 AM**: Off-peak schedule to minimize API load
- **Deduplication**: Post URLs checked against existing records to avoid redundant storage
- **Mock mode preserved**: When Apify key absent, returns realistic mock data (8 items per platform)
