# Video Ideas — 

---

### Rank 1 — "Stop Building AI Agents. You Probably Don't Need One."

**Angle:** A practitioner-level argument that the "agentic approach" is the wrong default for most use cases, using the sliding scale of autonomy as the diagnostic framework.

**Gap it fills:** Every existing video teaches HOW to build agents. None make the decision framework the centerpiece — the research explicitly identifies this "sliding scale" but doesn't give a usable heuristic for choosing sides.

**Audience desire:** "How do I know if I'm overcomplicating this?" — developers who've read the hype and suspect it doesn't apply to their actual problem.

**Competitive signal:** The research notes explicitly call out that "for narrow, well-defined problems, a fixed programmatic approach is often more efficient" — this is buried in the Q8 follow-up, which means existing videos mention it and move on without building a video around it.

**Hook direction:** Open with a real example of an agent someone built that should have been three if-statements — then ask why the industry never talks about this.

**Format recommendation:** Long-form 8–15min — the decision framework needs enough time to be genuinely useful, not a surface-level take.

---

### Rank 2 — "The ReAct Loop: Why Your AI Agent Gets Stuck in Circles"

**Angle:** A failure-mode dissection of the ReAct (Reason + Act) framework — what it looks like when the agent's observe-iterate cycle breaks down, and the three categories of failure nobody shows in tutorials.

**Gap it fills:** The research covers ReAct as a success story — "induce, track, update, handle exceptions." No existing content shows the failure modes: infinite loops, hallucinated tool calls, error propagation that ReAct was designed to avoid but doesn't always catch.

**Audience desire:** "My agent keeps looping / failing silently — why?" — builders who've implemented a tutorial agent and hit the wall when it doesn't work on their real data.

**Competitive signal:** ReAct is named explicitly in the research as a "prominent methodology," meaning it has tutorial saturation — but zero failure-mode coverage is the gap.

**Hook direction:** Show a live agent loop that doesn't terminate — let the viewer feel the frustration before explaining the taxonomy.

**Format recommendation:** Long-form 8–15min — each failure mode needs a concrete reproduction + fix to be actionable.

### Rank 3 — "AI Agents Cost 10x More Than You Think. Here's the Math."

**Angle:** A quantitative breakdown of latency and token cost differences between programmatic and agentic approaches for the same task, using the research's efficiency claims as the starting point.

**Gap it fills:** The research mentions that agentic systems are more computationally expensive but gives no numbers. No YouTube video has made a rigorous cost-per-query comparison the centerpiece — they all say "agents are more expensive" and move on.

**Audience desire:** "Can I actually afford to run this in production?" — founders and builders evaluating whether to commit to an agentic architecture.

**Competitive signal:** opensquilla (trending ~100 stars/day) is explicitly positioned as "token-efficient AI agent with same budget, higher intelligence" — the market is already voting that cost efficiency is the gap.

**Hook direction:** Open with a real invoice from a week of running an agent in production, then show what the programmatic version of the same workflow would have cost.

**Format recommendation:** Long-form 8–15min — the math needs to be shown, not summarized, to be credible.

### Rank 4 — "What Tools You Give Your AI Agent Is Everything"

**Angle:** Tool design as the primary leverage point for agent performance — not prompt engineering, not model choice, but what external programs the agent can reach and how they're shaped.

**Gap it fills:** The research lists web search, database queries, calculators, and other LLMs as tool categories but treats them as a given. No video focuses on tool design as a discipline: naming conventions, error return shapes, when to give fewer tools, how tool descriptions become part of the prompt.

**Audience desire:** "Why does my agent keep choosing the wrong tool?" — builders who have a working agent that misbehaves in non-obvious ways.

**Competitive signal:** "Tools" appear in every agent tutorial but always as setup boilerplate, never as the subject. This is the equivalent of "inputs are the most important part of a function" being skipped in every programming course.

**Hook direction:** Show the same agent with two tool sets — one poorly designed, one well-designed — and let the output difference make the argument before the explanation starts.

**Format recommendation:** Long-form 8–15min with a short-form 60–90s cut showing just the before/after agent behavior.

### Rank 5 — "Build a ReAct Agent From Scratch in 60 Lines of Python"

**Angle:** A from-scratch implementation that strips ReAct to its minimum viable form — no LangChain, no AutoGPT, just the loop — so the viewer understands the architecture before adopting a framework.

**Gap it fills:** Every tutorial starts with LangChain or a similar abstraction. The research notes name these platforms as solutions but the research on "how-to-train-your-gpt" (trending 84 stars/day) signals massive audience appetite for "build it yourself to understand it."

**Audience desire:** "What is actually happening inside LangChain's agent?" — developers who distrust black boxes and want to build before they abstract.

**Competitive signal:** raiyanyahya/how-to-train-your-gpt trending at 84 stars/day with "every line commented, explained like we're five" framing — the from-scratch + heavy annotation pattern is demonstrably drawing audiences right now.

**Hook direction:** Open by deleting the LangChain import and asking: "What's left?"

**Format recommendation:** Long-form 8–15min — the code walkthrough needs room to breathe; a 60-second cut won't serve the audience.

### Rank 6 — "AI Agent Memory Is Two Different Things. Most Tutorials Only Teach One."

**Angle:** A sharp distinction between internal reasoning logs (the agent's chain of thought) and conversation history (user personalization), explaining why conflating them produces agents that feel inconsistent or forget things they shouldn't.

**Gap it fills:** The research separates these cleanly — "internal logs of their own reasoning process" vs. "history of conversations with a human user" — but treats them as a footnote. No existing video makes the distinction the premise.

**Audience desire:** "Why does my agent feel like it has no memory even though I added memory?" — builders who wired up a memory module and still got inconsistent behavior.

**Competitive signal:** Memory is listed as one of the three core capabilities alongside Reasoning and Acting, but in tutorials it gets 10% of the airtime. That ratio is the gap.

**Hook direction:** Open with a user conversation where the agent forgets something it was just told, then reveal there are two separate memory systems and the wrong one was populated.

**Format recommendation:** Long-form 8–15min — the distinction needs enough worked examples to stick.

### Rank 7 — "Why AI Agents Hallucinate Less Than You Think (And When They Hallucinate More)"

**Angle:** A nuanced take on how ReAct's observe-and-iterate loop reduces hallucination compared to single-shot LLM calls — but creates a new category of error when the tool output itself is wrong or the agent's plan is structurally flawed.

**Gap it fills:** The research explicitly states that ReAct allows agents to "interface with external knowledge bases to overcome hallucinations" — but the flip side (tool-induced error propagation) is raised and immediately dropped. That second half is the video.

**Audience desire:** "Can I trust my agent's outputs in production?" — builders moving from demo to deployment who need to know what failure looks like.

**Competitive signal:** Hallucination is high-search-intent territory and has saturated the single-shot LLM space — but almost no content applies it specifically to agentic loop behavior.

**Hook direction:** Open by showing an agent confidently cite a Wikipedia article that doesn't exist — then reveal it was the tool that lied, not the model.

**Format recommendation:** Long-form 8–15min — the nuance requires case studies, not a list.

### Rank 8 — "The Only AI Agent Framework Comparison You Need (AutoGPT vs. LangChain vs. Scratch)"

**Angle:** A decision-tree comparison of the three practical paths — AutoGPT for workflow automation, LangChain for application development, raw implementation for understanding — anchored to specific use cases rather than feature lists.

**Gap it fills:** The research names AutoGPT and LangChain but never compares them against each other or against a DIY approach. Existing comparison videos list features; none give a "use this when X" decision rule.

**Audience desire:** "Which one should I actually use for my project?" — developers evaluating tooling before starting.

**Competitive signal:** Both platforms are named in research as go-to solutions, meaning viewers are already searching for them together. The decision-tree framing turns a feature comparison into a recommendation engine.

**Hook direction:** Open with a specific project type and pick the wrong framework on purpose — show the cost before explaining the correct choice.

**Format recommendation:** Long-form 8–15min — comparisons that don't go deep enough become superficial; this needs enough detail to be the definitive resource.

### Rank 9 — "What 'Think Slow' Actually Means in an AI Agent (And Why It Changes Everything)"

**Angle:** A conceptual unpacking of the "think slow" prompting technique — the practice of forcing an LLM to break a complex question into a plan before answering — explained through the lens of what changes in agent output when you apply it vs. when you skip it.

**Gap it fills:** The research mentions "think slow" as a key mechanism but defines it in one sentence. No existing video treats this as a standalone teachable concept despite it being the core reasoning mechanism that separates agent-grade prompting from standard prompting.

**Audience desire:** "Why does my agent jump to wrong answers on complex tasks?" — developers whose agents fail on multi-step problems because the model answers step 1 immediately instead of planning.

**Competitive signal:** Chain-of-thought prompting has millions of views in the academic framing — "think slow" is the practitioner translation that hasn't been claimed as a video topic.

**Hook direction:** Show the same three-step task answered by a standard prompt vs. a "think slow" prompt — let the output quality difference ask the question before you explain the mechanism.

**Format recommendation:** Both — a 60–90s short showing the output comparison, long-form explaining the mechanism and how to implement it in your own prompts.
