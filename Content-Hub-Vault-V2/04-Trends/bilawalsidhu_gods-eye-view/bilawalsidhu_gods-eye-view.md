## What problem does it solve?

Satellite and geospatial data (Sentinel, Landsat, weather, ship/plane tracking, etc.) is scattered across siloed, technical APIs that most people never touch. This project aggregates real open-source spatial intelligence feeds into one accessible, visual interface, letting anyone explore live global data without specialized GIS tools.

## How it works

It renders a photorealistic 3D globe in the browser (likely using a WebGL/Cesium-style rendering engine) and overlays live or near-live data pulled from open satellite and tracking APIs. Users can pan/zoom across the globe and toggle real-world data layers on top of the 3D terrain and imagery, turning raw geospatial feeds into an interactive simulator experience.

## Best use cases

- Educational tool for teaching geography, remote sensing, or satellite imagery concepts
- OSINT (open-source intelligence) research and monitoring of global events using public data
- Building or prototyping custom geospatial dashboards on top of the open-source globe engine

## Getting started

Clone the repo from GitHub and follow its JavaScript-based setup (likely npm install/npm run dev) to run the 3D globe locally in a browser, then explore the codebase to see which open data sources are wired in.
