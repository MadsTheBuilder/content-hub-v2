## What problem does it solve?

Developers and quant traders waste hours hunting across GitHub, Reddit, and forums to find reliable algorithmic trading tools — there's no single authoritative ranking of what's actually battle-tested. This repo solves the discovery problem by curating and ranking the best open-source trading frameworks, libraries, and resources in one place.

## How it works

It uses the 'best-of' format to generate a ranked list of projects scored by GitHub stars, updated on a weekly cadence. Projects are categorized by type (bots, backtesting engines, exchange connectors, TA libraries, etc.) and tagged by language, so the list is machine-generated from a structured source file rather than hand-edited.

## Best use cases

- A Python developer evaluating whether to use Freqtrade vs Jesse vs OctoBot for a crypto trading bot gets a side-by-side star-ranked comparison in seconds
- A quant researcher looking for backtesting engines across multiple languages (Zipline, backtrader, Lean, StockSharp) can filter by ecosystem without reading five separate READMEs
- A content creator or course author building a 'state of algo trading' overview can pull a structured, up-to-date snapshot of the ecosystem including communities, books, and YouTube resources

## Getting started

Visit the repo's README to browse the ranked tables directly — no install needed. If you want to contribute or run the list generator locally, the tooling is TypeScript-based and follows the standard best-of-lists CLI workflow.
