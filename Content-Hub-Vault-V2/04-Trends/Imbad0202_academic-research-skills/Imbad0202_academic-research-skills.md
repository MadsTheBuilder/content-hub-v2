## What problem does it solve?

Academics and researchers spend enormous time on the mechanical, repetitive parts of writing papers—literature search, drafting, citation checking, formatting, and iterative revision—time better spent on actual research thinking. This tool automates the full academic writing lifecycle so researchers can focus on ideas rather than process.

## How it works

It's structured as a pipeline of Claude Code skills covering research, writing, review, and revision stages, likely orchestrating searches, draft generation, and automated critique passes before producing a finalized document. Each stage feeds the next, letting Claude handle sourcing and drafting while a review/revise loop catches errors and weak arguments before finalization.

## Best use cases

- Drafting a literature review or related-work section from a research question
- Generating a full paper draft that gets automatically critiqued and revised for rigor and clarity
- Running a structured research → write → review cycle for thesis chapters or conference submissions

## Getting started

Clone the repo and install it as a set of Claude Code skills, then invoke the research/write/review/revise commands sequentially on a paper topic or existing draft.
