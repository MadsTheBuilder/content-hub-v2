## What problem does it solve?

Developers waste hours hunting for free APIs scattered across blogs, docs, and forums when building side projects, prototypes, or learning new integrations. This repo centralizes thousands of free public APIs in one categorized, searchable list, removing that discovery friction.

## How it works

It's a curated Markdown/JSON list (not a runnable service) organized by category (Animals, Finance, Weather, etc.), with each entry noting auth type, HTTPS support, and CORS status. Contributors submit new APIs via pull requests following a linting/formatting checklist, and the repo has spawned companion tools (search sites, API clients) built on top of its data.

## Best use cases

- Finding a free weather, geolocation, or currency API to power a hackathon or portfolio project
- Discovering data sources for a learning exercise on REST API integration or webhook handling
- Sourcing APIs to feed a no-code tool, chatbot, or aggregator app without paying for data access

## Getting started

Browse or search the README/index on GitHub for a category of interest, check the auth/HTTPS/CORS columns for the listed API, then sign up directly on that API's own site to get a key.
