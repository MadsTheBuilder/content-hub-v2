## What problem does it solve?

Developers accumulate personal workflow knowledge (debugging habits, review checklists, project conventions) as ad-hoc notes scattered across a `.agents` directory, with no easy way to package and share that tacit expertise as reusable, invocable units.

## How it works

The repo packages a collection of shell-based skill definitions that plug into an agent/CLI workflow, each one a self-contained script or instruction set an agent can invoke to perform a specific engineering task. Skills are organized as discrete files pulled directly from the maintainer's own working `.agents` directory rather than written as a generic showcase.

## Best use cases

- Bootstrapping a new agentic coding setup with battle-tested skill definitions instead of starting from scratch
- Standardizing team-wide engineering practices (code review, debugging, refactoring) as shareable, versioned agent skills
- Learning practical patterns for structuring shell-based automation for AI coding agents

## Getting started

Clone the repo and copy the relevant skill scripts into your own `.agents` (or equivalent) directory so your agent/CLI tooling can discover and invoke them.
