## What problem does it solve?

Setting up a fully configured Linux desktop from scratch is tedious and time-consuming — installing a window manager, theming, app defaults, and dev tooling one by one. Omarchy packages an opinionated, ready-to-go Arch-based Linux setup so developers get a polished environment immediately instead of hand-rolling dotfiles and configs.

## How it works

It's a shell-script-driven installer/config bundle that provisions an Arch Linux system with a pre-selected window manager (Hyprland-style tiling), themes, keybindings, and a curated set of applications and dev tools. Running the install script applies these opinionated defaults on top of a base Arch install, effectively turning a bare system into a cohesive desktop environment in one pass.

## Best use cases

- Quickly bootstrapping a new dev machine or VM with a consistent, aesthetically polished Linux desktop
- Standardizing a personal or team Arch Linux setup without manually configuring window manager and dotfiles
- Learning modern Linux ricing/tiling-WM conventions by studying a well-maintained opinionated config

## Getting started

Clone the omarchy repo and run its install shell script on a fresh Arch Linux installation to apply the full opinionated setup.
