## What problem does it solve?

Preparing for ML/AI job interviews requires mastering a vast, fast-moving landscape spanning LLMs, diffusion models, multimodal systems, and agents — but quality bilingual study materials that work offline and across devices are scarce. Candidates often waste time jumping between scattered resources in different formats and languages.

## How it works

The repo uses a Python-based ARIS workflow with a /render-html command that auto-generates self-contained single-file HTML cheat sheets covering ML, LLM, multimodal, diffusion, agent, and generative model topics. Because everything compiles into one HTML file, it requires no server, no app, and no internet — it opens natively on any device.

## Best use cases

- Chinese ML engineers preparing for fall recruitment (秋招) who need bilingual English/Chinese interview prep materials
- Self-taught developers wanting a portable, offline-ready reference for modern AI/ML concepts across phone, iPad, and laptop
- Content creators or educators looking for a template workflow to auto-generate structured HTML study guides from markdown or structured data

## Getting started

Clone the repo, ensure Python is installed, then trigger the ARIS /render-html workflow to generate the single-file HTML cheat sheets — open the output file directly in any browser with no additional setup required.
