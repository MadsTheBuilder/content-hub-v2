## What problem does it solve?

Crafting effective prompts for GPT-Image2 (and similar image-generation models) is largely trial-and-error, so creators waste time and credits guessing at wording instead of getting reliable, production-quality outputs. This repo solves that by treating prompting as an engineering discipline, giving creators battle-tested patterns instead of starting from scratch.

## How it works

It reverse-engineers 530+ real-world prompt examples to extract the underlying structural patterns, then packages those patterns into 20+ reusable, industrial-grade templates covering different image-generation use cases. From these templates it further distills reusable 'Skills' — higher-level, composable prompting techniques — that can be mixed and matched, with the whole library maintained as a JavaScript-based, continuously updated repo.

## Best use cases

- Generating consistent, on-brand marketing/product visuals by plugging details into proven prompt templates
- Learning prompt engineering for image models by studying reverse-engineered examples of what works
- Building internal tooling or pipelines that programmatically assemble prompts using the extracted Skills

## Getting started

Clone the repo and browse the template library and case studies to find a template matching your desired image type, then adapt it with your own subject/style details and run it against GPT-Image2.
