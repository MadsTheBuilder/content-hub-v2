## What problem does it solve?

Developers waste hours trying to understand unfamiliar codebases by reading files linearly, with no sense of how components connect. Static documentation and README files don't show relationships or let you ask questions about the code. There's no interactive way to explore a codebase's architecture the way you'd explore a map.

## How it works

Understand-Anything parses any codebase and builds an interactive knowledge graph where nodes represent code components and edges represent their relationships. The graph is explorable and searchable, and you can ask questions about it directly — making it a conversational interface on top of your code. It's built in TypeScript and integrates with major AI coding tools including Claude Code, Codex, Cursor, Copilot, and Gemini CLI.

## Best use cases

- Onboarding to a large open-source repo by exploring its structure visually before reading a single file
- Asking natural-language questions about how a specific module connects to the rest of the codebase
- Using it alongside AI coding assistants like Cursor or Claude Code to give the AI better context about the project graph before making changes

## Getting started

Since it works with existing AI coding tools like Claude Code and Cursor, a developer would point it at any local codebase and let it generate the knowledge graph, then explore or query it through their preferred AI assistant interface.
