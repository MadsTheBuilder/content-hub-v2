## What problem does it solve?

Most developers want to understand how large language models work under the hood, but existing resources are either too academic or skip over the implementation details. This repo bridges that gap by walking through building a modern LLM from scratch with every single line of code commented and explained in plain language.

## How it works

It's a Jupyter Notebook-based project where each cell builds incrementally toward a working GPT-style model, with inline comments explaining every decision in beginner-friendly terms. The notebook format means you can run, modify, and observe each component — tokenization, attention, transformer blocks — as you go rather than reading static theory.

## Best use cases

- Learning transformer architecture hands-on without needing a PhD-level math background
- Teaching LLM internals in a workshop or university course setting where runnable examples outperform slides
- Using it as a reference implementation to demystify what happens inside commercial models like GPT or Claude

## Getting started

Clone the repo, open the Jupyter Notebook in JupyterLab or VS Code, and run cells top to bottom — each cell is self-contained with comments explaining what it does before you need to understand why.
