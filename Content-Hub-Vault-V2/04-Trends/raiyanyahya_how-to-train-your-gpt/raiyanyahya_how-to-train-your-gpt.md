## What problem does it solve?

Most developers want to understand how LLMs actually work under the hood, but existing resources are either too academic or skip the implementation details. This repo solves the 'black box' problem by walking through every single line of code needed to build a modern LLM from scratch, explained in plain language anyone can follow.

## How it works

It's a Jupyter Notebook project, meaning each concept is broken into executable cells with inline comments explaining what every line does. The 'explained like we are five' approach means complex concepts like attention mechanisms, tokenization, and training loops are demystified step by step as you build them.

## Best use cases

- Learning how transformer architecture and GPT-style models work by building one from scratch
- Teaching or content creation — the heavily commented notebooks are ideal for walkthroughs, tutorials, and live coding demos
- Debugging intuition — understanding the internals makes it easier to reason about why production LLMs behave the way they do

## Getting started

Clone the repo, open the Jupyter Notebooks in order, and run each cell sequentially — the inline comments guide you through every step so no prior LLM internals knowledge is required.
