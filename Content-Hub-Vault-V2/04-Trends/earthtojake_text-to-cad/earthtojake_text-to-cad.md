## What problem does it solve?

Designing 3D models for CAD traditionally requires specialized software expertise and manual, time-intensive workflows that are inaccessible to most developers and non-engineers. This project bridges that gap by letting you describe what you want in plain text and have an AI coding agent generate the CAD model for you.

## How it works

It provides a set of CAD skills and harnesses — structured prompts and scaffolding — that plug into AI coding agents, translating natural language descriptions into 3D model code. The agent uses these skills to output geometry in a format compatible with standard CAD tooling, abstracting away the low-level CAD API calls.

## Best use cases

- Rapidly prototyping mechanical parts or enclosures by describing them in plain English
- Automating repetitive CAD tasks like generating parametric components with varying dimensions
- Enabling software developers without CAD expertise to produce 3D assets for hardware projects

## Getting started

Clone the repo from GitHub, install dependencies with npm, and follow the provided harness examples to wire up your preferred AI coding agent with the included CAD skills.
