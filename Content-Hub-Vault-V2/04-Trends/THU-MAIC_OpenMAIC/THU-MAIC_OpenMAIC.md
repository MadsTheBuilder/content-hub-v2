## What problem does it solve?

Educators want to deliver immersive, multi-agent classroom simulations but building the underlying agent orchestration, roleplay logic, and interactive UI from scratch is complex and time-consuming. OpenMAIC packages this into a one-click deployable system so classrooms can run multi-agent interactive learning experiences without custom engineering.

## How it works

It's a TypeScript-based platform that coordinates multiple AI agents (e.g., different personas, roles, or subject-matter experts) interacting with students in a shared classroom environment. The one-click setup handles agent orchestration and interactivity so users don't need to configure agent logic manually.

## Best use cases

- Simulated multi-perspective classroom discussions (e.g., debate between AI agents with different viewpoints)
- Role-play based language or soft-skills training with multiple AI characters
- Interactive tutoring scenarios where different agents specialize in different subjects or teaching styles

## Getting started

A developer would clone the THU-MAIC/OpenMAIC repo and use its one-click setup/deployment process to spin up the multi-agent classroom locally or on a server.
