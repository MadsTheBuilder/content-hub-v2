## What problem does it solve?

Many developers want to break into AI engineering but face a steep learning curve with no clear path from theory to production. Scattered resources leave them unsure what to build or how to ship real AI systems that others can use.

## How it works

It is a structured Python curriculum that walks developers through AI engineering concepts hands-on — building and shipping each component rather than just reading about it. The progression follows a learn-build-ship loop, grounding theory in working code at each stage.

## Best use cases

- A software engineer transitioning into AI roles uses it as a self-paced bootcamp to build a portfolio of shipped AI projects
- A team lead runs it as an internal study group to upskill backend engineers on LLM integration patterns
- A CS student supplements their coursework with practical AI engineering skills that go beyond academic ML theory

## Getting started

Clone the repo and work through the modules in order using Python — each module is self-contained with code you build, run, and ship. No prior AI experience is assumed, so starting from the first module is the recommended entry point.
