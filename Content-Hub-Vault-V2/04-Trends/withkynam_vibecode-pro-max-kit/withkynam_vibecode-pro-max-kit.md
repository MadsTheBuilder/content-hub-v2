## What problem does it solve?

AI coding assistants like Claude Code and Codex lose project context over time — they forget decisions, architecture, and conventions, leading to inconsistent spaghetti code. This 'context rot' forces developers to constantly re-explain their codebase and undo AI-generated regressions.

## How it works

It wraps Claude Code and Codex in a spec-driven harness with self-improving context memory, 12 specialized agents, and 32 pre-built skills. The system maintains persistent project knowledge so the AI always has the right context, routing tasks to the right agent rather than dumping everything into a single chat.

## Best use cases

- A solo developer shipping a SaaS product who wants the AI to remember architectural decisions across sessions
- A non-technical CEO or product owner directing AI agents to build features without writing code themselves
- A vibecoder prototyping fast who needs guardrails to prevent the AI from drifting into inconsistent implementations
