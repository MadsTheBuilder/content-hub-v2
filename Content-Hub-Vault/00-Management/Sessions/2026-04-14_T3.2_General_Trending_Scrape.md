# Session: T3.2 — General Trending Scrape Implementation

## What Was Done

Implemented platform-wide trending content discovery that runs on a weekly schedule and blends into suggestions. This additive feature does not change existing behavior.

### Key Implementation Details

1. **Sentinel Value Design**: Used `workflow_id = "__general__"` to tag general trending records in the existing `trending_content` table, avoiding the need for a DB migration.

2. **Apify Client Enhancements** (`backend/research/apify_client.py`):
   - Added `scrape_general_trending(platform: str)` async function to scrape platform-wide trending without keyword filtering
   - Added `_build_general_trending_input(platform: str)` helper to construct Apify actor inputs for broad trending hashtags (TikTok, Instagram) and trending feeds (YouTube)
   - Added `_mock_general_results(platform: str)` helper for mock mode testing
   - All results tagged with `workflow_id = "__general__"` for downstream identification

3. **Scheduler Integration** (`backend/scheduler/jobs.py`):
   - Added `job_general_trending()` async function for weekly platform-wide scraping
   - Registered with `CronTrigger(day_of_week="tue", hour=5, minute=0)` (Tuesdays at 5:00 AM)
   - Scheduler now manages 6 jobs total
   - Runs across three platforms: TikTok, Instagram, YouTube

4. **Suggestions Blending** (`backend/intelligence/suggestions.py`):
   - Fetch general trending tagged with `workflow_id = "__general__"` separately (limit 10)
   - Implemented `_blended_score()` function applying 0.6× weight multiplier to general trending posts
   - Workflow-specific posts take priority over general platform trends
   - Updated logger to report pool composition (workflow-specific + general trending count)
   - General trending items marked with `discovery_type = "general_platform_trend"` for user awareness

## Files Changed

- `/backend/research/apify_client.py` — Added 3 functions (scrape_general_trending, _build_general_trending_input, _mock_general_results)
- `/backend/scheduler/jobs.py` — Added import of scrape_general_trending, added job_general_trending() function, registered job with CronTrigger, updated job count to 6
- `/backend/intelligence/suggestions.py` — Added general trending fetch, implemented 0.6× weight blending via _blended_score(), updated logger message
