# Quick Copy Editing for Social Scripts

Apply these 4 editing passes in order, then run the quick-pass checks. Do NOT add data points, testimonials, or CTAs that don't exist in the original — only improve what's already there.

---

## Sweep 1: Clarity

**Focus:** Can the reader/viewer understand what you're saying instantly?

**Fix these:**
- Sentences trying to say too much — split or simplify
- Abstract language — replace with concrete examples
- Burying the point in qualifications — lead with the point
- Jargon the audience wouldn't use naturally
- Unclear pronoun references

**Rule of One:** Each section should have one main idea. If a sentence serves two purposes, it serves neither well.

---

## Sweep 2: Voice and Tone

**Focus:** Does the script sound like one consistent person?

**Fix these:**
- Shifts between formal and casual within the same piece
- Starting casual then becoming corporate
- Word choices that feel off-brand (too technical, too stiff, too salesy)
- Humor that appears randomly without setup

**Test:** Read it aloud. If any line sounds like a different person wrote it, smooth the transition.

---

## Sweep 3: So What

**Focus:** Does every claim answer "why should I care?"

**The test:** For every statement, ask "Okay, so what?" If the copy doesn't answer with a deeper benefit, it needs a bridge.

- BAD: "Our platform uses AI-powered analytics"
- GOOD: "AI-powered analytics surface insights you'd miss — so you make better decisions in half the time"

**Fix these:**
- Features listed without benefit connections
- Impressive-sounding claims that don't land emotionally
- Technical capabilities stated without real-world outcomes

---

## Sweep 4: Heightened Emotion

**Focus:** Does the copy make the reader *feel* something?

**Emotional dimensions to consider:**
- Pain of the current state (frustration, wasted time)
- Desire for transformation (what life looks like after)
- Pride in making a smart choice
- Relief from solving the problem

**Techniques:**
- Paint the "before" state vividly
- Use sensory, specific language (not abstract)
- Tell micro-stories (1-2 sentences that put the viewer in a scenario)
- Ask questions that prompt self-reflection

**Guardrail:** Emotion must serve the message. Heighten what's authentic, don't manufacture drama.

---

## Quick-Pass Word & Sentence Checks

**Cut these words:** very, really, extremely, incredibly, just, actually, basically, "in order to" (use "to"), unnecessary "that"

**Replace weak with strong:**

| Weak | Strong |
|------|--------|
| Utilize | Use |
| Implement | Set up |
| Leverage | Use |
| Facilitate | Help |
| Innovative | New |
| Robust | Strong |
| Seamless | Smooth |

**Sentence rules:**
- One idea per sentence
- Vary sentence length (mix short punchy with longer flowing)
- Front-load important information
- Max ~25 words per sentence
- Switch passive voice to active
